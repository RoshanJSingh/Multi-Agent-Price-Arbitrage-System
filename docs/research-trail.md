# Research Trail

The repository keeps the cleaned package code and the original experimental assets side by side:

- Amazon 2023 normalization work supports the 40k-record baseline.
- Frontier model notebooks show prompt baselines and fine-tuned model comparisons.
- RAG notebooks validate ChromaDB retrieval with 384-D sentence-transformer embeddings.
- Deal-agent notebooks show the incremental move from experiments to a Gradio workflow.
